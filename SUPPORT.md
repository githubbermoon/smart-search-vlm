# Support

## Before opening an issue

1. Read the README and runbook.
2. Update to the latest supported commit.
3. Confirm macOS, Apple Silicon, Python, Swift, and `uv` versions.
4. Run the relevant command from the repository root.
5. Search existing issues for the same symptom.

## Bug reports

Use the bug-report template and include reproducible steps, the commit hash, expected behavior, actual behavior, and sanitized logs. State whether the problem affects image ingestion, document ingestion, search, the macOS application, or Android access.

Do not attach personal media, private documents, databases, vector indexes, tokens, private network names, or unredacted absolute paths.

## Feature requests

Use the feature-request template. Describe the user problem before proposing an implementation and identify whether it belongs to the image pipeline, document pipeline, shared platform, macOS application, or mobile interface.

## Security issues

Follow [SECURITY.md](SECURITY.md). Security reports must not be filed publicly.

## Scope

Maintainers can help with reproducible project defects. General operating-system administration, private network configuration, third-party model availability, and unsupported hardware may be outside project support.
